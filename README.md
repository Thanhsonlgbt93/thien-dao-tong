# THIÊN ĐẠO TÔNG

Website tương tác tu tiên dành cho TikTok LIVE, giao diện ưu tiên điện thoại.

## Triển khai trên Render
- Tạo một **Static Site** mới trên Render.
- Kết nối GitHub repository: `Thanhsonlgbt93/thien-dao-tong`.
- Branch: `main`.
- Publish Directory: `.`
- Build Command: để trống.
- Có thể dùng Blueprint từ file `render.yaml`.

## Chức năng hiện có
- Cổng tiên môn và bảng hiệu THIÊN ĐẠO TÔNG.
- 5 tòa sen xếp hạng tu vi; 5 chân truyền, 5 nội môn, 24 ngoại môn.
- Bảng xếp hạng tặng quà.
- Bảng chỉ dẫn lệnh NAM, NỮ, TU VI và cách cộng điểm.
- Mô phỏng gia nhập, lượt thích, chia sẻ, quà tặng và tra cứu tu vi.
- Tiếng đọc tiếng Việt qua giọng nói có sẵn trên thiết bị.
- Dữ liệu mô phỏng được lưu trên trình duyệt của thiết bị.

## Lưu ý
Website hiện có chế độ mô phỏng để kiểm tra. Chưa có kết nối sự kiện TikTok LIVE thật hoặc cơ sở dữ liệu dùng chung giữa các thiết bị.
